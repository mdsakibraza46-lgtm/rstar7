About the Date Difference Calculator

Whether you are counting down to a deadline, measuring project duration or checking an eligibility window, you often need the exact gap between two dates.

Select the start and end dates. The calculator returns the total days between them (exclusive of the start day), the equivalent number of weeks, and the calendar difference in years, months and days.

Formula used

Days = (end date − start date) in 24-hour days, using the local calendar

Results are calculated in your browser — nothing is sent to or stored on any server.

Frequently asked questions

Are both start and end dates counted?

The count is the gap between the two dates: from 1 Jan to 31 Jan is 30 days. Add one if your use case is inclusive of both days.

What if the end date is before the start date?

The calculator asks you to correct it — dates must be in order — instead of returning a negative or scrambled result.

Does it handle leap years?

Yes — for example 28 Feb 2024 to 1 Mar 2024 is 2 days because 2024 is a leap year.
